## Qué es la Ingeniería de Software

Es la disciplina para resolver problemas mediante programas digitales.

- No es lo es lo mismo Ing. de Software que Ciencias Computacionales debido a que la segunda se dedica más a estudiarel funcionamiento de las computadoras.

- La ingeniería en Sistemas se basa más en desarrollo de sistemas basados en cómputo incluyendo hardware, software y la ingeniería de procesos.

- La ingeniería de Software es una parte de este proceso que comprende del desarrollo de software, control, aplicaciones y bases de datos del sistema.
