# CALIDAD DEL SOFTWARE

## Funcionalidad
 Existe para mostrar que el software realmente sirve para lo que fue exactamente creado

## Usabilidad
Mide el grado en el que un usuario específico puede usar un software para lograr una serie de objetivos cuantificados.

## Eficiencia
Está relacionada con el tiempo de respuesta a un estímulo o evento como una consulta dentro del software.

## Seguridad
Es la capacidad de un sistema para resistir al uso no autorizado, al mismo tiempo que proporciona sus servicios a usuarios legítimos.

## Mantenibilidad
Es fácil corregirlo, modificarlo y agregarle funciones.
Es normal el cambio o modificación durante su vida útil.

## Fiabilidad
Funciona correctamente y de manera consistente.
